# 🛒 BazzarOn API

BazzarOn is a modern, scalable RESTful API built for an e-commerce platform. It provides complete backend functionality for managing products, shopping carts, order processing, delivery tracking, and user authentication.

---

## 🚀 Key Features

* 📦 Catalog & Products: Category management, inventory tracking, search, and filtering.
* 🛍 Shopping Cart & Orders: Cart management, checkout workflows, order state tracking, and pricing calculations.
* 🚚 Shipping & Delivery: Delivery option selections, address management, and shipment status tracking.
* 👤 User Management & Security: User registration, JWT-based authentication, and role-based access control.

---

## 🛠 Tech Stack

* Framework / Platform: .NET / C#
* Architecture: Clean / Layered Architecture (src and Shared)
* Database: PostgreSQL / Entity Framework Core
* API Documentation: Scalar
